Agent City

See where agents write your code, and what it costs you.

Agent City turns a git repository into a 3D city. Files are buildings, folders are districts, height is how often a file changes. It shows where to review harder, what keeps getting reworked, where tests are missing, what only one person knows, and what changed since your team started using coding agents.

npx agent-city .

Runs on your machine and opens the city in your browser. Nothing is uploaded. Works on any git repository; agent records from Claude Code, Copilot, Cursor, Aider, Devin and git-ai add the agent view.

Explore an example

    What it answers

    1. Where do we need stricter review? Large files that change often, weighted by agent share when records exist.
    2. What keeps getting reworked? Files that need follow-up commits within 48 hours, overall and after agent changes.
    3. Where is the verifier missing? Source files that change while their tests never do.
    4. What does only one person know? Code with a single author, or written by agents with one human.
    5. What changed since agents arrived? Pace, change size, follow-ups and test habits before and after the first agent instruction file.
